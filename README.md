# Promise & Practice — Unit Two · Interactive Topical Assignments (Chapters 1–5)

Self-contained, offline-ready presentations for *Growth & Conflict, 1789–1877*.
Each folder is one presentation (`index.html`, fully embedded — no external files, no accounts).

## What's here
- `index.html` — the landing hub (four clickable image tiles)
- `the-anthem/` — close reading of the national anthem *(Ch. 1)*
- `fort-dearborn/` — massacre or battle? source corroboration *(Ch. 1)*
- `black-hawk-showpiece/` — the Black Hawk War, chunking the record *(Ch. 3)*
- `nauvoo/` — the Mormons in Illinois; a free press on trial *(Ch. 3–5)*
- `.nojekyll` — tells GitHub Pages to serve every folder as-is

## Deploy to GitHub Pages
1. Copy the entire contents of this folder into your repository (repo root, or a subfolder).
2. Commit and push.
3. In **Settings → Pages**, set the source to the branch/folder you pushed to.
4. The hub is at `…/index.html`; each tile opens its presentation.

Keep the folder names exactly as they are — the hub links to them by name.
